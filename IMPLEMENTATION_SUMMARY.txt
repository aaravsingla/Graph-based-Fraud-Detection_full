================================================================================
ALGORITHMS EXPLAINED (60 SECONDS)
================================================================================

LOUVAIN (Community Detection)
What:    Finds groups of tightly-connected nodes
Fraud:   Agencies sharing devices = fraud ring
Output:  communityId on each Agency node
Time:    30-60 seconds
Pattern: #5 (agency collusion)

PAGERANK (Centrality Ranking)
What:    Ranks nodes by structural importance
Fraud:   Important members = ringleaders
Output:  pageRankScore on each Member/Device node
Time:    30-60 seconds
Pattern: #10 (composite fraud score)

DEGREE (Hub Detection)
What:    Counts edges on each node
Fraud:   High-degree devices = proxy farms
Output:  inDegree on each Device/IP node
Time:    10 seconds
Pattern: #1, #3, #13 (shared artifacts)

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Graph not found"
Solution: Check ANALYTICS_GRAPH_ID from step 2 output

Problem: "Timeout waiting for status"
Solution: AWS operations can be slow; check manually via AWS console

Problem: "No results from queries"
Solution: Algorithms must run first; they stamp properties on nodes

Problem: "High costs"
Solution: Always pause graph when not running queries

See NEPTUNE_ANALYTICS_GUIDE.md → Troubleshooting for more
